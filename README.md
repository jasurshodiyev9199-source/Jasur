# VELORA Café

A responsive café website for VELORA, built with semantic HTML, CSS, and vanilla JavaScript.

## Run locally

Open `index.html` in a browser, or use the VS Code Live Server extension for a local preview. No build step or package installation is required.

## Features

- Responsive layout with an accessible mobile navigation menu.
- Filterable coffee and food menu.
- Reservation request form with required-field validation and a date that cannot be in the past.
- Newsletter sign-up interaction with inline feedback.
- Smooth in-page navigation, reduced-motion support, and keyboard-visible focus states.
- Café imagery and web fonts load from external services and require an internet connection.

## Customization

Update café details, menu items, and reservation time options in `index.html`. Visual styles are in `css/style.css`; interactive behavior is in `js/script.js`.

The reservation and newsletter forms currently provide client-side confirmation only. Connect them to a reservation service and mailing-list provider before using them to collect real submissions.
